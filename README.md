# OceanToken website demo

Static homepage snapshot with a browser-only FAQ assistant and cost estimator. No backend, API keys, or model requests are required.

Run locally with `python3 -m http.server 8766`, then open http://127.0.0.1:8766/. Deploy the repository root as a static site.

Lead submission is disabled. Production visitor telemetry is disabled in this copy. Signup and documentation links lead to the existing OceanToken services. The snapshot includes only homepage assets; other product routes may require the live service.

Internal documents, meeting notes, research, configuration credentials, and project history are excluded.
